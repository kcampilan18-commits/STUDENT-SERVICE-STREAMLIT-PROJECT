# Student Service Request Monitoring System

## Run locally
1. Install Python 3.10+.
2. Open a terminal in this folder.
3. Run `pip install -r requirements.txt`.
4. Run `streamlit run app.py`.

The trained Decision Tree pipeline is stored in `models/trained_model.joblib`. The app uses the supplied cleaned CSV for its default dataset. Predictions are advisory and require authorized staff review.
